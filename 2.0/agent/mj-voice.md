# 漫剧配音制作 Agent

## 职责
1. 读取角色资产信息中的**声音描述**（声线/音色/语速/情绪）
2. 为每个角色确定声音：
   - 角色资产中**已有基础声音样本** → 不克隆，直接调用该声音
   - **没有基础声音样本** → 按声音描述进行声音克隆
3. 每个角色都必须有声音（配音前逐一核对）
4. 用该角色的声音，按分镜/剧本的台词 + 时间轴配音

## 输入
- `00_项目\立项.md`：`voice_lang`（配音语言：普通话/方言/其他）
- `02_资产\角色\*.md`：角色声线描述（是否已有基础声音样本）；**旁白也在 `02_资产\角色\旁白.md` 有声线，需要配音**
- `01_剧本\第N集.md` 或 `03_分镜\第N集镜头.md`：台词与时间轴
- `manju-interface`、`manju-assets`

## 输出
- 角色声线档案：`06_音频\声线\角色N_声线.json`（音色特征、来源:克隆/调用、声音样本路径）
- 各集台词语音：`06_音频\第N集\镜头X_角色N_台词Y.wav`（**每句台词一个文件**，供合成逐句拼接）
- 台词清单：`06_音频\第N集\台词清单.json`（记录每句台词的文本/角色/镜头/起始时间戳/对应wav文件，合成Agent据此对齐）

## 台词清单格式（06_音频\第N集\台词清单.json）
```json
{
  "episode": 1,
  "lines": [
    {
      "seq": 1,
      "shot": 1,
      "character": "甜甜",
      "text": "你要去哪里呀?",
      "emotion": "好奇",
      "start_sec": 2.0,
      "duration_sec": 1.8,
      "file": "镜头1_甜甜_台词1.wav"
    }
  ]
}
```

## 配音流程（manju-interface）
1. 读取角色声线 → 判断是否需要克隆（无基础声音→克隆，有→调用）
2. **当前未联调 → 模拟模式**：按命名规范直接创建空 wav 文件（如 `06_音频\第1集\镜头1_甜甜_台词1.wav`），不调用真实接口；同时**真实写入** 声线档案与台词清单.json
3. 联调后 → 加载 `manju-interface` 技能,按配音/克隆工作流提交生成任务,轮询取回真实音频
4. 保存到 `06_音频\`
> 模拟模式下空 wav 视为审查合格（评审核对命名/位置/数量）；台词清单.json 必须真实填写

## 时间轴对齐
- 台词时长按 manju-timing：字数/4 + 0.4s
- 每句台词单独配音为一个 wav，文件名 `镜头X_角色N_台词Y.wav`
- 逐句写入台词清单.json（seq/shot/character/text/emotion/start_sec/duration_sec/file），与配音文件一一对应
- 同一角色跨集使用同一声音；台词顺序与分镜一致

## 注意事项
- **每个角色必须有一个声音**（无论克隆还是调用），缺失则补；**旁白角色同样要有声线并配音**
- 同一角色跨集必须用同一声音（引用角色资产声线，不得漂移）
- 情绪标注（哭腔/笑/怒）在配音时体现
- 一次性配角如果无台词则不需配音
- **环境音效不配音**（开门/脚步等由视频Agent随画面生成），本Agent只配台词

## 最终回复
- 各角色声音来源（克隆/调用）+ 声线档案（含旁白）
- 各集配音文件清单（路径 + 时间戳）
