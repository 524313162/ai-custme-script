# 漫剧评审技能(manju-review)

## 评审总原则
- 每个环节完成后必须评审，通过才进入下一环节
- 评审只做核对与结论，不替代产出；发现问题记录问题清单交导演打回原Agent
- 同一环节最多打回 2 次；第 3 次仍不通过 → 升级给用户决策
- 引用一致性是核心：任何环节不得擅自改写资产文件中的外貌/声线
- **立项字段一致性**：每个环节的产出都必须符合 `00_项目\立项.md` 中导演引导确认的立项项（美术风格/画幅/配音字幕语言/片头片尾等），不符合视为 Revise
- **模拟模式判定**：接口未联调时，生成类产物（图片/视频/音频）为**空文件**——评审以命名/位置/数量/清单完整性为准，空文件视为合格；文本类清单（台词清单.json/BGM时间点对齐文件）必须真实、完整

## 通用评审步骤
1. 读取该环节产物文件 + `00_项目\立项.md`(目标时长/世界观/集数)
2. 读取 `02_资产\*` 核对引用一致性（含"图片提示词"区块完整性）
3. 按下方对应环节规则逐项核对
4. 输出结论:
   - ✅ Pass:进入下一环节
   - ❌ Revise:列出编号问题(RV-01、RV-02…)+ 期望/实际差异
5. 评审结论统一落盘到 `00_项目\评审\<环节名>.md`(剧本.md/分镜.md/图片.md/配音.md/音乐.md/视频.md/合成.md),供导演决策

## 环节评审规则

### ① 剧本评审(编剧产出)
- [ ] **每集时长 ≥ 2 分钟(硬指标,按 manju-timing 公式逐项自算,剧本内附自算明细)**
- [ ] **故事完整:起承转合齐全**(起因→发展→转折→结果/钩子),不能是片段
- [ ] 每章 ≥ 1 个剧情热点(冲突/转折/钩子/笑点/泪点)
- [ ] 台词量匹配画面节奏:不多不少、**旁白克制**(不算配音泛滥;旁白需登记在角色\旁白.md)
- [ ] 资产信息齐全:角色含**外貌+声线**;场景含**详细布局**(摆件相对位置);道具/BGM/音乐结构完整
- [ ] 角色行为符合世界观;资产可供分镜引用
- [ ] **片头/片尾标注**(仅立项勾选片头片尾时才有)

### ② 分镜评审(分镜产出)
- [ ] **每个分镜条目都包含固定模板全部字段:画面内容 + 资产引用 + 时长 + 转场 + BGM**
- [ ] 引用资产均能在 `02_资产\` 中找到
- [ ] 白名单只含反复出现、需高度一致的内容(主角/固定房间/常用道具/BGM/技能特效)
- [ ] **一次性资产不入白名单**(若混入→打回删除)
- [ ] 镜头总时长 ≈ 剧本时长(≥2分钟)
- [ ] **每个镜头时长在 5~10 秒内**(超10s必拆、不足5s必并;**转场镜头可3~5秒**)
- [ ] **镜头编号连续**(镜头1、镜头2…),与视频Agent产出 `镜头X.mp4` 一一对应
- [ ] **转场连贯**:每个镜头标注转场方式;存在纯转场镜头时有明确内容(如空镜+叠化)
- [ ] 镜头语言/景别/BGM时间点标注齐全

### ③ 图片评审(图片产出)
- [ ] **每个资产文件内有"图片提示词"区块(正向+反向)且内容真实**(不在独立提示词.md中;角色/场景/道具/BGM/音乐均需)
- [ ] 角色:一张图 = 立绘+三视图(左侧立绘+右侧正/侧/背)
- [ ] 场景:俯视图产出,**布局与资产文件"布局"描述吻合**
- [ ] 道具:双视图产出
- [ ] 跨图一致(发型/服装/特征引用资产文件,不漂移)
- [ ] 美术风格符合 `立项.md` 的 `art_style`;分辨率符合 `aspect_ratio`

### ④ 配音评审(配音产出)
- [ ] **每个角色都必须有声音**(克隆或调用,无一遗漏;**含旁白角色**)
- [ ] 声线与资产文件一致;同一角色跨集同一声线
- [ ] **台词清单.json 存在且完整**(每句含 seq/shot/character/text/emotion/start_sec/duration_sec/file)
- [ ] 每句一个 wav,文件与台词清单一一对应、顺序正确
- [ ] 时间轴与分镜对齐(manju-timing);情绪表达符合剧本标注(哭/笑/怒)
- [ ] **无环境音效配音**(音效不入台词清单)

### ⑤ 音乐评审(音乐产出)
- [ ] BGM 覆盖分镜标注的全部时间点
- [ ] **音乐提示词(正向+反向)写入资产文件"图片提示词"区块**(真实)
- [ ] 风格/情绪符合世界观与用途(温馨/紧张/悲伤);全剧统一
- [ ] 片头尾曲(如有)时长合适、可并入成片(与片头尾画面模板对齐)

### ⑥ 视频评审(视频产出)
- [ ] **每个镜头有视频生成提示词文件 `镜头X_视频提示词.md` 且内容真实**(含图片内容描述、合并图顺序或单角色图、场景图说明、画面内容、动作、时长、**环境音效描述**、**转场**)
- [ ] 镜头与分镜一一对应,数量/时长匹配(每镜5~10s);镜头文件命名 `镜头X.mp4` 与分镜编号一致
- [ ] 画面内容符合分镜(人物/场景/道具正确;多角色镜头合并图有左上角标签、顺序与提示词一致;**单人镜头不生成合并图**)
- [ ] **画面含环境音效(随画面生成);不含BGM/配音**——BGM/配音由合成Agent混入
- [ ] 片头片尾画面模板仅立项勾选时产出(存放 `05_视频\片头片尾\`)
- [ ] 临时合并图放 temp\（仅多角色镜头）

### ⑦ 合成评审(合成产出)
- [ ] **文本类产物真实**(字幕srt、HTML播放器、时间轴/合成清单)——不得为空
- [ ] 字幕齐全(每集都有)且时间轴与台词清单对齐
- [ ] 字幕内容语言符合 `立项.md` 的 `subtitle_lang`
- [ ] 视频画幅/分辨率符合 `aspect_ratio`;交付物形式符合 `deliverables`
- [ ] BGM/配音混音音量合理(BGM低于人声);片头尾曲与画面拼接正确(仅立项勾选时)
- [ ] M3U8 + HTML 播放器可播放、可选集(未具备ffmpeg时,空文件占位视为合格)
- [ ] 全片合并(如已导出)完整、可播放

## 输出格式
```markdown
# 评审结论:[环节名]
结论: ✅ Pass / ❌ Revise
问题清单:
- RV-01: [问题描述](期望 vs 实际)
- RV-02: ...
建议: (打回给哪个Agent / 升级用户)
```
