# 漫剧多Agent制作流程 · 设计总览(v3)

## 工作目录
- 默认:`D:\00-Manju-Workspace`
- 若目录不存在/无法写入 → 导演必须询问用户指定存放位置
- 项目目录 = `<工作目录>\<项目名>\`(项目名由用户提供或从需求提炼)

## 立项引导（导演开工必做，用户没想到的必须主动问）
立项不能只记"项目名+集数"。以下关键项用户通常不会主动提，但决定全流程产物形态，导演必须逐项引导确认，不得擅自假设：
- **A. 必问**：① 画幅/目标平台（竖屏9:16漫剧主流 vs 横屏16:9）；② 题材与受众（奇幻/都市/治愈/搞笑…儿童/成人）；③ 美术风格（水彩/日系动漫/简约/写实…）；④ 配音语言（普通话/方言/其他）；⑤ 字幕语言（中文/双语）；⑥ 原创或改编（版权）；⑦ **总集数**（10~40集常见20~25集，不得默认1集）
- **B. 建议确认**：⑧ 片头片尾（**默认无**，仅用户明确要求才加）；⑨ BGM风格；⑩ 交付物（HLS播放器+MP4）；⑪ 每集时长（默认≥2分钟/集）
- **C. 引导方式**：逐项提问给选项和默认值；用户"随便/你定"的项按合理默认确定并**记录进 立项.md**，不可事后漂移
- 全部确认后写入 `00_项目\立项.md`(MD格式,固定模板见 mj-director)，后续所有 Agent 只读该文件，不再重复问用户

## 标准目录结构(全局唯一编号,消除歧义)
```
<工作目录>\<项目名>\
├─ 00_项目\立项.md                 # 导演产出:项目名/故事名/总集数/每集时长/画幅/题材受众/美术风格/配音字幕语言/原创改编/片头片尾/BGM风格/交付物/流程状态
├─ 00_项目\评审\                   # 评审Agent产出:剧本.md/分镜.md/图片.md/配音.md/音乐.md/视频.md/合成.md
├─ 01_剧本\第1集.md ~ 第N集.md     # 编剧产出:每集故事(每集≥2分钟,完整起承转合,含剧情热点+片头片尾标注+时长自算)
├─ 02_资产\                        # 编剧产出"资产信息草案",分镜定"白名单"；图片/音乐提示词(正向+反向)写在各资产文件内的"图片提示词"区块
│   ├─ 角色\角色1.md               #   外观(供图片)、声线(供配音)、图片提示词区块(图片Agent写回)
│   ├─ 角色\旁白.md                #   旁白角色:只登记声线,不出图
│   ├─ 场景\场景1.md               #   布局(每个摆件相对位置)+图片提示词区块
│   ├─ 道具\道具1.md               #   外观+图片提示词区块
│   ├─ BGM\BGM1.md                 #   用途/风格 + 音乐提示词区块(作曲Agent写回)
│   └─ 音乐\片头或片尾曲.md         #   仅立项勾选片头片尾时存在
├─ 03_分镜\第1集镜头.md ~ 第N集镜头.md   # 分镜产出(固定模板):每镜【画面内容】+【资产引用】+【时长】+【转场】+【BGM】,每镜5~10秒,镜头编号连续
├─ 04_图片\                        # 图片Agent产出(每资产一张图,由资产文件内提示词生成)
│   ├─ 角色\角色1.jpg              #   一张图=立绘+三视图
│   ├─ 场景\场景1_俯视图.jpg
│   └─ 道具\道具1_双视图.jpg
├─ 05_视频\第1集\镜头1.mp4…第1集.mp4 + temp\   # 视频Agent产出(每镜头视频+成片;画面含环境音效;多角色镜头才生成temp\镜头X_合并.png,单人无)
├─ 05_视频\第1集\镜头X_视频提示词.md  # 视频Agent产出(每镜头:图片内容描述+合并图顺序或单角色图+画面说明+环境音效+转场)
├─ 05_视频\片头片尾\片头.mp4 片尾.mp4   # 视频Agent产出(仅立项勾选时)
├─ 06_音频\                        # 配音Agent产出(声线\、第N集\台词清单.json+逐句wav)+ 音乐Agent产出(BGM\、音乐\)
├─ 07_字幕\第1集.srt               # 合成Agent按台词清单生成(无独立字幕Agent)
└─ 08_导出\index.html + playlist.m3u8 + 全片合并.mp4   # 合成Agent产出
```

## 流程与评审关卡(每环节后必评审)
```
① 立项 导演Agent         → 00_项目\立项.md(固定模板逐项引导,含总集数必问;目录不存在则询问,默认 D:\00-Manju-Workspace)
② 剧本 编剧Agent         → 01_剧本 + 02_资产\*资产信息草案(角色:外貌+声线;场景:详细布局;旁白登记声线)
   ├─ 剧本评审: 每集时长≥2分钟(硬指标,附公式自算) / 故事完整起承转合 / 剧情热点≥1 / 资产信息合理 / 片头片尾标注
③ 分镜+资产白名单 分镜Agent → 03_分镜(固定模板:画面内容+资产引用+时长+转场+BGM;剔除一次性资产)
   ├─ 分镜评审: 镜头用到的资产是否已提取 / 有无一次性资产(有则打回删除) / **每镜5~10秒(超10拆/不足5并;转场镜头3~5秒)** / 镜头编号连续 / **转场连贯标注**
④ 资产图片 图片Agent     → 02_资产\*提示词区块(正向+反向,真实写入资产文件内) + 04_图片(角色一张图=立绘+三视图/场景俯视图/道具双视图)
   ├─ 图片评审: 每资产有提示词区块(正向+反向) / 规格达标(角色立绘+三视图?场景俯视?道具双视?) / 美术风格/画幅一致 / 场景布局吻合
⑤ 配音 配音Agent         → 06_音频\声线\+第N集\(每句wav+台词清单.json;克隆/调用角色声线;旁白配音)
   ├─ 配音评审: 每个角色必须有声音(含旁白);声线一致;台词清单完整;时间轴对齐
⑥ 音乐 音乐Agent         → 06_音频\BGM + 片头尾曲(仅立项勾选时;按分镜BGM时间点);提示词(正向+反向)写入资产文件
   ├─ 音乐评审: BGM覆盖分镜时间点 / 风格统一 / 片头尾曲时长合适(如有)
⑦ 视频 视频Agent         → 05_视频(每镜头:镜头X_视频提示词.md真实+镜头X.mp4;含环境音效;多角色才合并图;片头片尾画面模板仅立项勾选时)
   ├─ 视频评审: 每镜有视频提示词(含图片内容描述/合并图顺序/环境音效/转场) / 镜头齐全 / 时长匹配5~10s / 画面与分镜一致 / 单人镜头无合并图
⑧ 合成 合成Agent(唯一混音方) → 混音(BGM+配音;环境音效已在画面内,不再处理)+片头尾拼接(仅勾选时) + 字幕(07_字幕\第N集.srt,真实) + M3U8 + HTML播放 + 可导出合并
   └─ 用户审核 → 用户确认导出 → 全片合并
```

## 模拟与真实边界(重要)
- **一切文本/规划类产物必须真实**:剧本、资产、分镜、视频提示词、资产内提示词区块、台词清单.json、BGM对齐文件、字幕srt、HTML → 真实写入,禁止空文件
- **生成类产物模拟**:接口未联调时,图片/视频/音频 → 创建规范命名的**空文件**占位,视为审查合格(评审核对命名/位置/数量/对应提示词)
- **导出类产物模拟**:依赖 ffmpeg 的混音成片/HLS切片/M3U8/全片合并 → 未具备环境时空文件占位
- 真实环境就绪后,由真实工作流/ffmpeg 覆盖空文件

## 职责边界(重要)
- **混音唯一负责方 = 合成Agent**:视频Agent产出画面+环境音效(随画面生成);配音与BGM统一在合成阶段混入,不重叠
- **环境音效不配音**:开门/脚步/开关声等由视频Agent在视频提示词中描述、随画面生成,音频Agent不处理
- **配音粒度 = 每句一个wav + 台词清单.json**:合成按 seq/start_sec 逐句对齐
- **片头片尾默认无**:仅立项.md 勾选时才产出；视频Agent出画面模板;音乐Agent出曲;合成Agent拼接混入
- **旁白 = 角色(只有声音)**:登记声线、参与配音,不出图、不进合并图
- **提示词内嵌资产文件**:图片/音乐提示词(正向+反向)不单独建 .md,统一写入资产文件内"图片提示词"区块(见 manju-assets 固定模板)
- **评审落盘 = `00_项目\评审\<环节名>.md`**

## 资产白名单规则
- 编剧产出资产信息草案时,一次性资产可先不写或少写
- 分镜Agent明确"整剧反复出现、需高度一致"的资产(主角/固定房间/常用道具/BGM/技能特效)列为白名单
- 一次性资产不生成图片,避免浪费
- 每个分镜条目必须包含:画面内容 + 资产引用(字符ID必须能在02_资产中找到)+ 时长 + 转场 + BGM

## 生成接口(预留占位)
- **本质是 ComfyUI 工作流**:图片/音乐/配音/视频各有独立工作流,工作流不同参数读取方式不同
- 当前仅预留统一流程骨架(读资产内提示词→提交→轮询→取回→记录)
- **模拟模式(当前默认)**:接口未联调前,生成类Agent不调用真实接口,改为创建规范命名的**空文件**代替产物(如 `04_图片\角色\阿乐.jpg`、`05_视频\第1集\镜头1.mp4`、`06_音频\BGM\旧时光.mp3`);空文件视为审查合格,评审核对命名/位置/数量
- **提示词必须真实并内嵌资产文件**:图片/音乐提示词(正向+反向)写入资产文件"图片提示词"区块；每个镜头视频对应 `05_视频\第N集\镜头X_视频提示词.md`,这些是评审依据,先于产物写入
- 导出(ffmpeg 混音/切片/合并)未具备环境时同样空文件占位
- 具体工作流/API/参数/产物获取方式**待联调后填充**;未联调前不得臆造接口细节
- 视频工作流规划约束:预期只接受 2 张图片 + 1 个提示词(第1张=场景图,第2张=合并图或单角色图)
