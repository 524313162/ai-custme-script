# 漫剧资产规范技能(manju-assets)

## 资产文件位置
`<工作目录>\<项目名>\02_资产\` 下按类型分目录:
- `角色\角色1.md`
- `场景\场景1.md`
- `道具\道具1.md`
- `BGM\BGM1.md`
- `音乐\片头或片尾曲.md`(仅立项勾选片头片尾时)

## 资产内提示词区块(固定模板,各生成Agent产出时追加)
所有资产文件末尾统一追加以下区块,**由对应生成Agent(图片/作曲)写入真实内容**,是评审依据:
```markdown
## 图片提示词(图片Agent/作曲Agent生成,评审依据)
### 正向提示词
(详细描述:版式约定 + 全部外形特征 + 美术风格 + 画幅 + 光线氛围)
### 反向提示词
(要避免的内容:多余肢体/畸形手/文字水印/低质量/模糊/其他角色乱入等)
### 一致性要求
(引用本文件哪些字段,跨集不得漂移;同一人不同年龄段的延续感等)
```
> 提示词不单独建 .md 文件,统一写在资产文件内。

## 资产白名单规则
- **白名单资产**:整剧反复出现、需要高度一致的内容 → 必须提取并生成图片/声音(主角、固定房间、常用道具、BGM、技能特效)
- **一次性资产**:整剧只出现一次的 → 不提取、不生成图片(如某集一次性的路人/临时场景)
- 每个分镜条目必须注明用到的资产引用;评审核对:镜头用到的资产必须在白名单/02_资产中存在,一次性资产不允许进入白名单

## 一致性要求
- 所有 Agent 描述同一角色时,必须引用该角色的资产文件,不得自行改写外貌/声线
- 图片/配音生成时以资产文件为准,保证跨集一致
- 场景图必须以资产文件的**布局描述**为准,不得自行挪动摆件位置
