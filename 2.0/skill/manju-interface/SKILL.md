# 漫剧生成接口技能(manju-interface)

## 接口性质(重要)
- **本质是 ComfyUI 工作流**,不是固定 HTTP API。
- 图片、音乐、配音、视频各自对应**不同的工作流** → 工作流节点、输入参数、输出读取方式都不一样。
- 当前阶段:**仅预留调用流程与占位**,具体工作流(workflow json / API 地址 / prompt 参数结构 / 输出文件位置)待真实工作流就绪后按实际情况补充到本技能,并同步到各生成 Agent。
- 任何 Agent **不得臆造**具体的 URL、字段名、参数结构;未联调前,遇到需要真实调用时标记"接口待联调"并反馈导演。

## 模拟模式(接口未联调时默认执行,重要)
**未联调前,生成Agent不调用任何真实接口,改为"创建规范命名的空文件"代替产物**,目的是让每个步骤的产物都真实落盘、可被导演审查(命名/位置/数量/清单)。规则:
- 直接创建空文件(内容为空,仅占位),文件名与存放位置严格遵循各生成类型的命名规范(见下表)
- **模拟模式下,生成的图片/视频/音频空文件一律视为"审查合格"**——评审只核对命名/位置/数量/清单完整性,不核对真实内容
- **提示词必须真实写入资产文件内**(见 manju-assets"图片提示词"区块);视频提示词写入 `05_视频\第N集\镜头X_视频提示词.md`——它们是评审依据,先于产物写入
- 文本类清单(台词清单.json、BGM时间点对齐文件)必须**真实写入内容**(供评审对齐),不能为空
- 导出类产物(依赖 ffmpeg 的混音成片/HLS切片/M3U8/全片合并)未具备环境时同样**空文件占位**
- 空文件创建方式:新建即可(如 New-Item / touch),不写内容、不伪造数据
- 真实工作流联调完成后,移除模拟模式,恢复真实生成(接口联调后各Agent按真实工作流产出并覆盖空文件)

## 统一流程(各工作流通用骨架)
1. 读取对应资产文件/分镜内容 → 编写提示词/参数
2. 按该类型的 ComfyUI 工作流提交生成任务
3. 轮询/等待任务完成(取任务状态)
4. 取得产物(图片/音频/视频)保存到项目对应目录
5. 记录任务标识与产物路径(便于评审追溯)

## 各生成类型的提示词要点(与工作流无关,可提前规划)
| 类型 | 提示词要素 | 产物规格 |
|---|---|---|
| 图片-角色 | 资产内正向提示词:资产外貌 + **一张图=立绘+三视图**(左侧大立绘+右侧正/侧/背) | JPG,一致性:跨集引用资产文件 |
| 图片-场景 | 资产内提示词:场景描述 + **严格按布局**(每个摆件位置) + 俯视图 | JPG |
| 图片-道具 | 资产内提示词:道具外观 + **双视图**(左右两个面) | JPG |
| 音乐/BGM | 资产内提示词:用途情绪 + 风格乐器 + 节奏 + 时长 | 音频文件 |
| 配音 | 角色声线 + 台词 + 情绪 + 时间戳 | 台词语音文件 |
| 视频 | 视频提示词文件(图片内容描述+合并图顺序+画面内容+动作+时长+环境音效) + 场景图 + 合并图 + 台词时间轴 | 镜头视频 |

## 视频工作流的特殊约束(重要,需与视频工作流设计对齐)
- **规划约束**:视频工作流预期只接受 **2 张图片 + 1 个提示词**:
  - 第 1 张图 = 场景图
  - 第 2 张图 = 合并图(该镜头用到的所有人物 + 道具,从上到下排列)
- 合并图制作规则(视频 Agent 负责,不依赖接口):
  - 将镜头内全部角色与道具图片按"上→下"纵向合并为一张
  - **每张子图的左上角用宋体写上角色名/道具名**(便于模型区分)
  - 合并图存放于 `05_视频\第N集\temp\`
  - **单人无需合并图**:若该镜头只有 1 个角色且无道具 → 第 2 张图直接使用该角色的立绘图片,不生成合并图
- 提示词 = 视频提示词文件内容(画面内容 + 动作 + 台词时间轴 + **环境音效描述**)
- **环境音效随画面生成**:开门声/脚步声/开关声等在视频提示词中详细描述,由视频工作流一并生成,不进入后期配音
- 此约束待真实视频工作流联调后确认/调整
