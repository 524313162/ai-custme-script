# 漫剧时长估算技能(manju-timing)

## 适用场景
- 编剧:创作剧本时自检"这一集能不能演满2分钟""台词会不会不够/太多"
- 分镜:给每个镜头估算 duration_sec
- 配音:给每句台词分配时间戳
- 合成:核对全片时长

## 核心参数(可被 立项.md 覆盖)
- 默认每集目标时长:`≥ 120 秒`(2分钟,用户要求"不低于2分钟")
- 人语速:中文约 4 字/秒
- 台词停顿:每条台词 +0.4 秒
- 动作/叙事段:约 2.5 秒/条
- **环境音效:不单列计时**(开门声/脚步声/开关声等在视频生成提示词中详细描述,随视频画面生成,不占配音时长)
- 场景切换:(场景数-1) × 1.5 秒
- 片头/片尾:**默认无**(仅立项.md 明确勾选时各计约 10 秒)

## 时长公式
```
台词秒     = Σ(每条台词字数 ÷ 4) + 0.4 × 台词条数
旁白秒     = 旁白按角色台词计,一般不常出现
动作秒     = 动作/叙事段条数 × 2.5
环境音效   = 0(随视频画面生成,不单列)
切换秒     = (场景数 - 1) × 1.5
片头片尾   = 默认0(立项勾选时 10+10)
单集总长   = 台词秒 + 旁白秒 + 动作秒 + 切换秒 + 片头片尾
```

## 达标标准
- 单集总长 **≥ 120 秒**(最低要求;推荐 120~150 秒,宁多勿少)
- 若低于120秒 → 需扩充剧情/台词/动作,避免"台词不够"或"画面空转"
- 若明显超过(如>180秒)→ 检查是否台词过多/节奏拖沓,适当精简

## 镜头时长硬约束(重要,分镜必须遵守)
- **单个镜头时长控制在 5~10 秒**,不能太短、不能太长
- 镜头时长 = 该镜头内 台词秒 + 动作秒 + 音效秒 之和
- 超 10 秒 → 必须拆成多个镜头(把该镜头内容按动作/台词切段拆分)
- 不足 5 秒 → 并入相邻镜头,或扩充动作/音效/过渡,不能留"碎片镜头"
- 分镜拆镜头时以"5~10秒容量"为单位:先按剧本场景分段,再逐段套用公式确认时长
- 检查:镜头数 × 平均6~8秒 ≈ 该集正文时长(不含片头尾),可反推镜头数量是否合理

## 检查清单(评审用)
- [ ] 每集台词量是否与该集时长匹配(按公式逐项加总,不以字数粗估)
- [ ] 是否有大段无台词、无动作的空白
- [ ] 片头片尾(如立项勾选)是否已计入时长
- [ ] 分镜每个镜头的 duration_sec 之和 ≈ 该集总长
- [ ] **每个镜头 duration_sec 是否都在 5~10 秒内**(超10s必拆,不足5s必并)
